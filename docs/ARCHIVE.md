# Archived MPC experiment

The predecessor explored a deterministic Rust sequencer and guarded integration
with the Akai MPC Sample stock application. It established useful rules around
integer musical time, deterministic ordering, fail-closed firmware validation,
bounded real-time work, reversible experiments, and honest separation of host,
emulator, and physical-device evidence.

It is preserved locally at branch
`archive/mpc-sample-experiment-2026-11-18` and annotated tag
`mpc-sample-experiment-final`, both rooted at commit `8ce9232`. No archive refs
were pushed by this task.
